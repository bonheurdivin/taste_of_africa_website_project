# Tastes of Africa

### Exploring Africa's culinary heritage, one dish at a time.

Tastes of Africa is a responsive, multi-page website celebrating the diversity, flavours, and cultural traditions of African cuisine. It introduces visitors to some of the popular African dishes, their origins, traditional ingredients, and cooking methods while encouraging them to explore the culinary heritage of different regions.

The project combines a modern editorial-style design with interactive features to create an engaging and informative experience.

---

## About the Project

African cuisine reflects the continent's rich history, geography, and cultural diversity. From West African Jollof Rice to Ethiopian Injera and Moroccan Tagine, every dish tells a story.

Tastes of Africa brings selected culinary traditions together in one place, allowing visitors to discover recipes, explore regional food cultures, and learn about the importance of African cuisine.

### Project Objectives

- Celebrate and promote African food heritage.
- Introduce visitors to traditional dishes and their cultural backgrounds.
- Provide recipes and cooking instructions.
- Explore the ingredients and cooking techniques of different African regions.
- Apply HTML5, CSS3, JavaScript, and DOM manipulation in a practical project.

---

## Website Features

The website contains **12 HTML pages**, organised into the following sections:

| Page | Description |
|---|---|
| Home | Introduction, featured dishes, regional highlights, and food stories |
| Recipes | Recipe collection with search and regional filters |
| Jollof Rice | Nigerian Jollof Rice recipe |
| Tagine | Moroccan Tagine recipe |
| Injera | Ethiopian Injera recipe |
| Isombe | Rwandan Isombe recipe |
| Regions | Directory of African culinary regions |
| West Africa | West African food culture and traditions |
| East Africa | East African food culture and traditions |
| North Africa | North African food culture and traditions |
| About | Project mission and African culinary heritage |
| Contact | Contact form and visitor feedback |

### Interactive Features

- **Recipe filtering and search:** Find dishes by name or filter them by region.
- **Favourites:** Save preferred recipes using browser `localStorage`.
- **Ingredient scaling:** Adjust recipe quantities according to the number of servings.
- **Dark and light mode:** Switch between themes, with the selected preference saved.
- **Contact form:** Validate visitor information and display a personalised confirmation message.
- **Responsive navigation:** Mobile-friendly navigation menu.
- **Newsletter feedback:** Provides confirmation feedback when visitors submit the newsletter form.

The website also includes embedded YouTube videos, Google Maps, expandable cooking instructions, and food photography.

## Design and Responsiveness

The website follows a modern African editorial design inspired by food magazines and culinary travel publications.

DM Serif Display is used for headings, while DM Sans provides readable body text.

CSS Grid, Flexbox, flexible sizing, and media queries help the website adapt to mobile phones, tablets, and desktop screens.

Accessibility considerations include semantic HTML, descriptive image alternative text, labelled form fields, keyboard focus indicators, and accessible interactive controls.

## Getting Started

To run the project locally:

**1. Clone the repository**

```bash
git clone https://github.com/bonheurdivin/taste_of_africa_website_project.git
```

**2. Open the project folder**

```bash
cd taste_of_africa_website_project
```

**3. Open it in Visual Studio Code**

```bash
code .
```

**4. Run the website**

Open `index.html` using the Live Server extension in Visual Studio Code, or open the file directly in your browser.

---

## Limitations

Some features are frontend demonstrations:

- **Contact form:** Displays a confirmation message but does not send information to a backend.
- **Newsletter:** Provides feedback after submission but does not connect to an actual mailing service.
- **External media:** Embedded YouTube videos and Google Maps require an internet connection.
